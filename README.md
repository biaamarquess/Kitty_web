# Kitty_web
Projeto desenvolvido com finalidade de criar um chat web, sendo possivel mandar e enviar mensagens.

# Objetivo Do Projeto 
Esse projeto foi desenvolvido com muito carinho para criar um chat web com o tema da Hello Kitty. A ideia era combinar funcionalidade com um visual delicado e mais descontraido. O layout foi pensado para ser leve, com tons de rosa, ícones fofos e uma interface amigável. Utilizamos HTML, CSS e JavaScript para estruturar o front-end, e implementamos um sistema básico de troca de mensagens em tempo real. O objetivo foi proporcionar uma experiência divertida e acolhedora para quem adora conversar online com um toque de magia da Hello Kitty!

# Observação:
O chat está responsivo então você pode utilizá-lo tanto em um notebook quanto em um celular
